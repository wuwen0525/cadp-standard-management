# 中国灾害防御协会团体标准管理平台

面向协会内部使用的团体标准全过程管理静态原型。

## 主要功能

- 项目台账与进度维护
- 提案至出版的 15 节点流程跟踪
- 待补材料识别与处理
- 办理记录与本地自动保存
- 已发布团体标准库
- 协会标准化体系建设任务

## 本地使用

直接打开 `index.html`，或通过任意静态文件服务器运行。

> 当前版本使用浏览器 `localStorage` 保存修改记录，适合原型验证和单机使用。正式多人使用需要接入用户权限、数据库和文件存储服务。

## 数据说明

项目和标准数据由本地材料目录整理形成。待补材料根据文件名称和当前流程环节自动比对，仅用于提示，需管理员人工确认。
